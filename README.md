# Moderno e modernismo

Página estática de apoio didático para o Senac Lapa Scipião.

## Publicação no GitHub Pages

1. Crie o repositório público `modernismo-senac` na conta `DanielMalva`.
2. Envie o conteúdo desta pasta para a branch `main`.
3. Em **Settings → Pages**, escolha **Deploy from a branch**, branch `main` e pasta `/(root)`.
4. A página ficará disponível em `https://danielmalva.github.io/modernismo-senac/`.

Ao fim da disciplina, despublique a página em **Settings → Pages**. Em seguida, se desejar, torne o repositório privado. No GitHub Free, a página de um repositório privado é despublicada automaticamente.
